Installation

Method 1 — Upload in WordPress (recommended)

1
Log in to your WordPress admin and go to Plugins → Add New Plugin.
2
Click Upload Plugin, choose skill-whatsapp-chat-pro.zip and press Install Now.
3
Click Activate. A new menu item WhatsApp Chat appears in the left admin menu.

Method 2 — FTP / File Manager

1
Unzip the package on your computer.
2
Upload the folder skill-whatsapp-chat-pro to /wp-content/plugins/.
3
Activate it from Plugins.

Updating from version 2.x

Deactivate and delete the old version (your settings stay in the database), then install v3 and activate. Your number, messages, colours and hours are migrated automatically. The old “Hide on pages” list becomes a Hide on selected pages display rule.

Quick start in 5 minutes

1
Add your number. Open WhatsApp Chat → General and type your number in international format: country code + number, digits only. Example for Pakistan: 923001234567 (not 03001234567). Click Test — WhatsApp should open with a test message.
2
Write your welcome text. Set the agent name, status line and welcome bubble.
3
Match your brand. In Design, choose a preset or your own colours and watch the preview on the right.
4
(Optional) Add agents in Agents — e.g. Sales, Support, Billing.
5
Save with the top-right button or Ctrl/⌘ + S. Visit your website — the button is live.
Tip: open the site in a private window to see it exactly as a new visitor (with auto-open and badge).

Agents

Route visitors to the right person or department. With one active agent the popup shows a chat bubble; with two or more it shows a selectable list.

1
Click Add agent.
2
Fill Name, Role / department, Phone (international format) and optionally a custom pre-filled message for that agent.
3
Click the round avatar to choose a photo from the Media Library.
4
Drag the handle to reorder. Use the switch to temporarily deactivate an agent, or to remove.
Agents without a valid number are skipped when saving. If no agent is active, the main number from General is used.

Business Hours

1
Turn on Enable business hours.
2
Choose a Timezone (e.g. Asia/Karachi) or keep “Use WordPress timezone” (Settings → General).
3
Tick open days and set From/To. Night shifts like 22:00 → 02:00 are supported. Use Copy Monday to all weekdays to speed things up.
4
Choose When offline: show the offline message (status dot turns grey and the offline text is pre-filled) or hide the widget entirely.
If you use full-page caching, online/offline status reflects the time the page was cached. Set the cache lifetime to 1 hour or less for accurate status.

Developer hooks & CSS

Filter: swcp_should_show

// Hide the widget on the "blog" category archive
add_filter( 'swcp_should_show', function ( $show, $settings ) {
    return is_category( 'blog' ) ? false : $show;
}, 10, 2 );

Action: swcp_settings_saved

// Purge your cache plugin after saving
add_action( 'swcp_settings_saved', function ( $settings ) {
    if ( function_exists( 'rocket_clean_domain' ) ) rocket_clean_domain();
} );

Google Analytics 4 / Tag Manager

If gtag() is on the page, these events are sent automatically:

gtag('event', 'whatsapp_open');                       // popup opened
gtag('event', 'whatsapp_click', { agent: 'a1b2c3d4' }); // chat started

// Google Tag Manager dataLayer
{ event: 'swcp_open' }  /  { event: 'swcp_click', swcp_agent: 'main' }

In GA4 go to Admin → Events and mark whatsapp_click as a key event to track it as a conversion.

Security & Performance

Security

  • All admin AJAX actions require manage_options + a WordPress nonce.
  • Every setting is whitelisted and sanitised on save and import (numbers, colours, URLs, enums, times, timezones).
  • All output escaped (esc_html, esc_attr, esc_url).
  • Tracking endpoint is nonce-protected and rate-limited per visitor.
  • Links use rel="noopener noreferrer nofollow".
  • Direct file access blocked in every PHP file.

Performance

  • Frontend: one ~8 KB CSS + one ~4 KB deferred JS, no jQuery, no fonts.
  • Assets load only on pages where the widget is shown.
  • Bootstrap, icons and Chart.js are bundled and load only on the plugin’s admin page — no CDN calls.
  • Analytics uses sendBeacon (non-blocking) and a non-autoloaded option.
  • Respects prefers-reduced-motion; accessible labels & focus states.

How WhatsApp click-to-chat works (2026)

  • The plugin uses WhatsApp’s official link format https://wa.me/<number>?text=<message>. It works with both WhatsApp and WhatsApp Business — no API key or Meta approval needed.
  • On phones it opens the WhatsApp app; on desktop it opens WhatsApp Desktop or WhatsApp Web.
  • The number must include the country code and have no +, spaces, brackets or leading zero (the plugin cleans these for you).
  • The visitor always sends the first message, so no message templates or 24-hour window rules apply.
  • Recommended: use the WhatsApp Business app for auto-greeting, away messages, labels and quick replies that complement this widget.

Troubleshooting

ProblemSolution
Button does not appearCheck: widget enabled, valid number, Display Rules, device setting, business hours “hide” mode, logged-in hiding. Then clear your cache plugin and CDN.
“Phone number shared via url is invalid”The number lacks a country code or isn’t on WhatsApp. Use the Test button.
Button hidden behind another elementRaise Z-index or change offsets.
Wrong online/offline statusCheck the timezone and your page-cache lifetime.
Saving shows an errorYour session may have expired — reload the page. Security plugins blocking admin-ajax.php must allow swcp_* actions.
Analytics stay at 0Ensure Built-in analytics is on; some ad-blockers block tracking requests; cached pages may hold an expired nonce (keep cache ≤ 12 h).
