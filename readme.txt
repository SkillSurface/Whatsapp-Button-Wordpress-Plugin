Professional WhatsApp floating chat & multi-agent support widget with a modern Bootstrap 5.3 dashboard.

== Description ==
* Floating WhatsApp button with popup chat window (single or multi-agent)
* Up to 20 agents / departments with avatars, roles, custom messages, drag & drop ordering
* Live preview (desktop / mobile) inside the dashboard, AJAX save (Ctrl/Cmd + S)
* Business hours with timezone and overnight ranges, offline message or auto-hide
* Display rules: devices, include/exclude pages via AJAX search, hide for logged-in users, hide on WooCommerce checkout
* Scroll trigger, auto-open, tooltip, notification badge, pulse/bounce/shake animation
* Light / dark / auto themes, shapes, sizes, colour presets, custom icon, custom CSS
* Privacy-friendly built-in analytics (no IPs / cookies) + GA4 / GTM events
* GDPR consent checkbox
* Dynamic placeholders: {page_title} {page_url} {site_name}
* Shortcode: [whatsapp_button text="Chat" style="pill" align="center"]
* Import / export / reset, clean uninstall option
* Uses official https://wa.me/ click-to-chat links. No external requests; all libraries bundled.

== Installation ==
1. Plugins → Add New → Upload Plugin → choose the zip → Install → Activate.
2. Open "WhatsApp Chat" in the admin menu, enter your number, save.
